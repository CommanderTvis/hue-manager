Hue Manager

Philips Hue lamp management with daylight automation — Linux desktop app, distributed as a Flatpak. Nightly builds from master.

Install

flatpak install --user https://commandertvis.github.io/hue-manager/hue-manager.flatpakref

Update

flatpak update io.github.commandertvis.huemanager

Run

flatpak run io.github.commandertvis.huemanager
